# AGENTS.md

Guidance for AI coding agents. Humans: start with [README.md](README.md) and [CONTRIBUTING.md](CONTRIBUTING.md).

## What this is

Personal **bilingual** (EN default, JA) tech blog, statically generated by [gohan](https://github.com/bmf-san/gohan) (a Go SSG) and hosted on Cloudflare Pages. Architecture & URL design: [docs/DESIGN_DOC.md](docs/DESIGN_DOC.md). Deploy/CI/operations: [docs/OPERATIONS.md](docs/OPERATIONS.md).

## Commands (the Makefile is the source of truth — run `make help`)

- `make install-gohan` — install the pinned gohan (`GOHAN_VERSION` in [Makefile](Makefile))
- `make build` — build the site into `public/`
- `make serve` — dev server at http://localhost:1313 (live reload)
- `make new-ja TITLE="…" SLUG=slug` / `make new-en TITLE="…" SLUG=slug` — scaffold a post
- `make lint-content-diff` — textlint only changed post bodies (this is what CI runs); `make lint-content` lints everything
- `make check-parity` — EN/JA `translation_key` parity; `make check-content` — gohan built-in checks
- `make test-e2e` — Playwright E2E (run `make build` first)

## Content rules

- Posts live in `content/en/posts/*.md` and `content/ja/posts/*.md`. Create them with `make new-*`, don't hand-copy. Frontmatter & slug rules: [CONTRIBUTING.md](CONTRIBUTING.md). `slug` is lowercase-hyphen ASCII.
- **Translation parity**: every non-draft post's `translation_key` must exist in BOTH `en` and `ja` (CI `parity.yml`). Set `draft: true` on a work-in-progress translation to skip the check.
- Changing a published URL requires adding a redirect — see [CONTRIBUTING.md](CONTRIBUTING.md) / [docs/OPERATIONS.md](docs/OPERATIONS.md).
- `public/` is generated build output (gitignored). Never edit it by hand.

## Editing pitfalls (read before touching posts)

- CI `lint-content-diff` runs textlint on the WHOLE of each changed post body, so editing an old post surfaces its pre-existing lint errors (weak expressions 思う/かも, full-width `？`/`！`, ら抜き言葉, doubled particles, write-good) — you must fix them for CI to pass. **Frontmatter-only edits are not linted.**
- JA rules ([.textlintrc-ja.json](.textlintrc-ja.json)): sentence ≤120 chars, no ら抜き言葉, no redundant/weak expressions, statement-ending `？`/`！` → `。`. EN rules ([.textlintrc-en.json](.textlintrc-en.json)): write-good + terminology (e.g. `nginx`→`Nginx`, `Docker-compose`→`Docker Compose`).
- When editing Japanese/CJK text, type literal characters (not `\uXXXX` escapes) and re-check every edited line with `git diff` — a wrong or dropped kana (especially in katakana or book titles) is a common silent error.

## Theme / templates

HTML templates live in `themes/default/templates/`. Styling uses [sleyt](https://github.com/bmf-san/sleyt) CSS utility classes loaded via CDN. Do NOT add inline `<style>`; add new CSS to the sleyt repo and bump its version ([CONTRIBUTING.md](CONTRIBUTING.md)).

## Branches, PRs, deploy

- No direct push to `main` (protected). Branch prefixes: `feat/ fix/ docs/ design/`. PRs are self-merge OK.
- PR titles must be Conventional Commits with a **lowercase** subject (CI `semantic-pr.yml`); types: `feat fix docs style refactor perf test build ci chore revert`.
- Push to `main` auto-deploys via GitHub Actions → Cloudflare Pages. Future-dated posts stay unpublished until a daily scheduled deploy reaches their date ([docs/OPERATIONS.md](docs/OPERATIONS.md)).
