A staged reading list for anyone learning databases, from SQL basics to design and operations. Each pick has its own review on this blog, and every entry links to it. The order follows a learning path: SQL basics, deeper SQL, design, PostgreSQL, and distributed data.

## Why learn databases

Most applications lean on a database to store and retrieve data. Master SQL and design basics, and you head off performance problems and data inconsistencies early. Learn the product-agnostic principles, and your skills travel when the stack changes.

## 1. Get started with SQL

### Learning SQL, 3rd Edition

A hands-on classic for learning core SQL syntax. It suits anyone who touches a database for the first time. I cover it in the [review](/posts/beginner-sql-third-edition/).

### Practical Introduction to SQL

It explains fast, readable queries through the lens of execution plans. You learn to write not just correct SQL, but quick SQL. I dig into it in the [review](/posts/sql-practical-introduction/).

## 2. Go deeper with SQL

### The Complete SQL Guide for Advanced Beginners

It covers window functions, CASE expressions, and other next-step techniques. It suits readers ready to move past the basics. My notes are in the [review](/posts/sql-master-guide-for-advanced-beginners/).

### SQL Antipatterns

It pairs common design and coding mistakes with their causes and fixes. Knowing the traps up front saves rework. See the [review](/posts/sql-anti-patterns/).

## 3. Design your database

### The Complete Guide to Database Design

It walks through normalization and table design from a practical angle. It helps you set a solid design foundation. I wrote it up in the [review](/posts/db-design-guide-for-beginners/).

### A Practical Introduction to Databases from Theory

It derives sound design from the relational model. You come to understand the thinking behind SQL. I cover it in the [review](/posts/database-practical-introduction-relational-model/).

## 4. Master PostgreSQL

### The Complete Guide to PostgreSQL, 4th Edition

A broad reference on PostgreSQL, from install to operations. It guides you as you start using it at work. My notes live in the [review](/posts/postgresql-comprehensive-guide/).

### Understanding PostgreSQL from Its Internals

It explains indices and transactions through their internal structures. Design and operations calls gain solid backing. I dig into it in the [review](/posts/postgresql-internal-structure/).

## 5. Extend to distributed data and caching

### A Comprehensive Guide to Trino

A practical guide to Trino, which queries across many data sources. It helps you build a foundation for large-scale analytics. See the [review](/posts/trino-sql-query-engine-guide/).

### Practical Introduction to Redis

It covers Redis, an in-memory data store, from mechanics to field use. It widens your options for caching and session management. I cover it in the [review](/posts/redis-practical-introduction/).

## Wrap-up

Start with the two SQL primers, then raise quality with design and antipatterns. Go deep on PostgreSQL and distributed data once your target is clear. Every book has a full review here, so start with whichever one interests you most.
