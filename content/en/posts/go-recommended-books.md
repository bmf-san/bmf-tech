A staged reading list for anyone learning Go, from the basics to real practice. Each pick has its own review on this blog, and every entry links to it. The order follows a learning path: language basics, a deeper understanding of the language, and web, systems, and distributed implementation.

## Why learn Go

Go pairs a small syntax with a strong standard library and first-class concurrency, and backend teams use it widely. Its surface area stays compact, so you reach real work quickly. Once you learn it, you apply it across CLIs, web services, and cloud infrastructure.

## 1. Get started with Go

### Starting with Go

A gentle introduction to Go's syntax and basics for newcomers. You move through it as a comfortable first read. I cover it in the [review](/posts/starting-with-golang/).

### Learning Go, 2nd Edition

It teaches idiomatic Go for people who already know another language. You pick up Go-native style from the start. I wrote it up in the [review](/posts/idiomatic-go-practice-guide/).

## 2. Understand the language deeply

### The Go Programming Language

A staple from the language's designers that treats the spec with care. You come to understand the thinking behind the syntax. My notes are in the [review](/posts/programming-language-go/).

### Practical Go

It gathers broad, practical Go style that pays off in the field. Read it after the basics to build strength. See the [review](/posts/practical-go-language/).

### 100 Go Mistakes and How to Avoid Them

It explains common mistakes through a hundred concrete cases. Knowing the traps up front saves rework. I cover it in the [review](/posts/golang-100-tips-common-mistakes/).

## 3. Build web services and systems

### A Practical Introduction to Go Web Programming

It follows building a web app from scratch with the standard library alone. You gain a foundation that does not lean on a framework. My notes are in the [review](/posts/golang-web-app-development-from-scratch/).

### Web Application Development with Go

It teaches web development in Go through worked examples. You grasp routing and templates in concrete terms. I wrote it up in the [review](/posts/web-application-development-with-golang/).

### Understanding System Programming with Go

It teaches low-level mechanics like system calls and memory through Go. You deepen your grasp of the parts you usually cannot see. See the [review](/posts/go-system-programming/).

## 4. Toward distributed systems

### Distributed Services with Go

It builds a distributed service in Go, from log collection to consensus. You experience design and implementation aimed at production. I cover it in the [review](/posts/distributed-services-with-golang/).

## Wrap-up

Start with the two primers to get comfortable with the syntax, then raise your writing with the deeper books. Pick the web, systems, or distributed titles to match what you want to build. Every book has a full review here, so start with whichever one interests you most.
